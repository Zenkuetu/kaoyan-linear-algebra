# 标准形与规范形

> <span class="oneline">**一句话**：标准形只留平方项，再缩放成系数 $1,-1,0$ 叫规范形</span>

**考试层次**：`数一` ｜ **章节**：[[第六章 二次型|第六章 二次型]]

## <span class="hx hx-pain">🟠</span> 一、先看要解决什么

**化标准形要解决的是：把二次型的交叉项全部消掉，让符号一眼可见。**
拿一个具体的来：

$$
f = 2x_1^2 + 2x_1x_2 + 2x_2^2
$$

它显然不是恒正的"显然"吗？代 $(1,-1)$ 得 $2 - 2 + 2 = 2 > 0$，代 $(1,-2)$ 得 $2 - 4 + 8 = 6 > 0$ —— 试了十几个点都大于零，可这不算证明。麻烦就卡在那个交叉项 $2x_1x_2$ 上：它随 $x_1$、$x_2$ 变号，把平方项的正负搅在一起，光看系数根本说不清 $f$ 到底是正是负。

最容易想到的办法是硬套"完全平方公式"：$2x_1^2 + 2x_1x_2$ 看着像 $2(x_1 + \frac{1}{2}x_2)^2$ 的开头，写出来

$$
2x_1^2 + 2x_1x_2 + 2x_2^2 = 2\left(x_1 + \frac{1}{2}x_2\right)^2 + \frac{3}{2}x_2^2
$$

（验算：右边展开是 $2x_1^2 + 2x_1x_2 + \frac{1}{2}x_2^2 + \frac{3}{2}x_2^2 = 2x_1^2 + 2x_1x_2 + 2x_2^2$，对得上。）这个式子确实把交叉项消掉了、只剩平方项，可是它带着一层壳：**它是"两个数的平方和"，系数 $2$ 和 $\frac{3}{2}$ 不是原始特征值**，换成 $f = 5x_1^2 + 4x_1x_2 + 2x_2^2$ 就得重配一遍，没有一个统一的说法。

## <span class="hx hx-gap">🔴</span> 二、直接办法为什么不够

所以不能见一个配一个，得先想清楚"消掉交叉项以后该长什么样"：

- <span class="pit">**坑一 · 拿配方结果直接当标准答案**</span>：配出来的 $2(x_1+\frac{1}{2}x_2)^2 + \frac{3}{2}x_2^2$ 里还留着"$x_1 + \frac{1}{2}x_2$"这种复合的括号，不同的人配法不同、结果也不同，没法当成"标准形"来互相比较；
- <span class="pit">**坑二 · 以为标准形唯一**</span>：$f = 2x_1^2 + 4x_1x_2 + 4x_2^2$ 经不同替换可化成 $2y_1^2 + 2y_2^2$、也可化成 $y_1^2 + y_2^2$（前者见配方篇），系数完全不同 —— 谁也不是"唯一正确"的那个，所以不能拿两个标准形逐项比系数来判断二次型是否等价；
- <span class="pit">**坑三 · 忘了标准形里可能有零项**</span>：$f = x_1^2 - x_2^2$（加个不出现的 $x_3$）看着是三元，化完只有两个平方项，秩是 $2$ 而不是 $3$，遗漏掉"零系数项"就会把秩数错。

## <span class="hx hx-intro">🟢</span> 三、于是引入：标准形与规范形

于是引入两个层次：**标准形**是只含平方项、没有交叉项的形式

$$
f = d_1y_1^2 + d_2y_2^2 + \dots + d_ny_n^2
$$

**规范形**是标准形里把系数进一步缩放成只剩 $1$、$-1$、$0$ 的形式

$$
f = y_1^2 + \dots + y_p^2 - y_{p+1}^2 - \dots - y_{p+q}^2
$$

上面那三个坑，逐个补上：

- <span class="fix">**坑一补上 · 括号要拉平成单变量**</span>：配方得的 $2(x_1+\frac{1}{2}x_2)^2 + \frac{3}{2}x_2^2$ 里，把 $y_1 = x_1 + \frac{1}{2}x_2$、$y_2 = x_2$ 当成新变量（这是可逆替换，因为由 $y$ 能唯一解回 $x$），标准形就是 $2y_1^2 + \frac{3}{2}y_2^2$ —— 干干净净只剩平方，每个 $y_i$ 单打独斗；
- <span class="fix">**坑二补上 · 用规范形当"公约数"**</span>：$2y_1^2 + \frac{3}{2}y_2^2$ 与 $4z_1^2 + z_2^2$ 系数不同，但各自把正系数缩成 $1$（$y_1 \mapsto u_1/\sqrt{2}$、$z_1 \mapsto u_1/2$）都能变成 $u_1^2 + u_2^2$。**标准形不唯一，规范形唯一**，比较两个二次型一律走规范形；
- <span class="fix">**坑三补上 · 零项明明白白写出来**</span>：$f = x_1^2 - x_2^2$ 的规范形写成 $y_1^2 - y_2^2 + 0 \cdot y_3^2$，零项的个数是 $n - r$（这里 $3 - 2 = 1$），秩 $r$ 与项数一起数，不会漏。

> 顺带提一句：这里"用可逆替换把矩阵变简单、再看剩下的不变量"，到附录会换一套说法。名字换了，算法一模一样，现在不懂它照样能把题做完。

## <span class="hx hx-detail">🔵</span> 四、细节

<span class="lab">**定义**</span>：若存在**可逆**线性替换 $x = Cy$（$C$ 可逆），把 $f = x^{\mathrm{T}}Ax$ 化成只含平方项的形式 $d_1y_1^2 + \dots + d_ny_n^2$，就称后者为 $f$ 的一个**标准形**；若进一步把系数缩放成只取 $1$、$-1$、$0$，得到的就是**规范形**，形状是

$$
f = y_1^2 + \dots + y_p^2 - y_{p+1}^2 - \dots - y_{p+q}^2
$$

<span class="lab">**算例**</span>：把 $f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 化成标准形与规范形。
第一步，配方（分解成两个平方）：

$$
f = 2\left(x_1 + \frac{1}{2}x_2\right)^2 + \frac{3}{2}x_2^2
$$

第二步，把括号拉平成新变量：令 $y_1 = x_1 + \frac{1}{2}x_2$、$y_2 = x_2$，反解出 $x_1 = y_1 - \frac{1}{2}y_2$、$x_2 = y_2$，即

$$
x = \begin{pmatrix} 1 & -\frac{1}{2} \\ 0 & 1 \end{pmatrix} y
$$

这个矩阵的行列式是 $1 \neq 0$，可逆，合法。于是标准形是

$$
f = 2y_1^2 + \frac{3}{2}y_2^2
$$

第三步，化规范形：令 $y_1 = \frac{1}{\sqrt{2}}u_1$、$y_2 = \sqrt{\frac{2}{3}}u_2$，两个系数都被拉成 $1$：

$$
f = u_1^2 + u_2^2
$$

所以规范形是 $u_1^2 + u_2^2$。
<span class="lab">**验算**</span>：取 $(x_1, x_2) = (1,1)$，$f = 2 + 2 + 2 = 6$；此时 $y_1 = \frac{3}{2}$、$y_2 = 1$，$2 \times \frac{9}{4} + \frac{3}{2} = 6$，对上了。再取 $(1,-1)$：$f = 2 - 2 + 2 = 2$；$y_1 = \frac{1}{2}$、$y_2 = -1$，$2 \times \frac{1}{4} + \frac{3}{2} = 2$，也对上了。

<span class="lab">**秩与零项**</span>：标准形里系数为零的项数 = $n - r(A)$。例如 $f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 的矩阵是 $\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$，$\lvert A \rvert = 3 \neq 0$，$r = 2 = n$，没有零项；而三元 $f = x_1^2 - x_2^2$（矩阵 $\mathrm{diag}(1,-1,0)$）秩 $2$，规范形里带一个零项。

**两种化法**（后面各有一篇细讲）：
- 配方法：只要 $C$ 可逆，配出什么系数就是什么系数，**不需求特征值**；
- 正交变换法：要求 $A$ **实对称**，取正交矩阵 $Q$，标准形系数恰好就是 $A$ 的全部特征值。

<span class="key">**常用结论**</span>：
- 标准形**不唯一**（换一个可逆替换就可能得到另一组系数），但**规范形唯一** —— 这是惯性定理的内容；
- 所以判断两个二次型是不是同一类，要比较的是"正项个数、负项个数"，而不是逐项比系数。

## <span class="hx hx-usage">🟣</span> 五、怎么用

1. 选择题：给标准形问规范形，或给两个不同标准形问它们是否等价 —— 一律先数正、负平方项个数，个数一样就是同一类（如 $3y_1^2 + y_2^2$ 与 $4z_1^2 + z_2^2$ 都属于"两个正项"，等价）。**数二不要求**化标准形与规范形的方法，只要求了解这两个概念，这类选择题在数二卷子里以概念判断为主。
2. 填空题：填标准形/规范形的形状（如"规范形为 $\underline{\quad}$"）或填系数。**数二不要求**掌握化法，一般不会让数二考生自己动手化。
3. 解答题：给 $f$，要求一个可逆替换把它化成标准形并写出该替换 —— 这是数一的常考大题（配方法或正交变换法皆可），**数二不要求**。

## <span class="hx hx-err">⚠️</span> 六、易错点

- ⚠️ 把"标准形唯一"当结论使用
