# 线性空间与子空间

> <span class="oneline">**一句话**：八条法则全成立才叫线性空间；封闭性验子空间</span>

**考试层次**：`数一` ｜ **章节**：[[附录 线性空间与线性变换|附录 线性空间与线性变换]]

## <span class="hx hx-pain">🟠</span> 一、先看要解决什么

**线性空间要解决的问题是：矩阵、多项式、方程组的解这些"不是向量"的东西，能不能也像向量一样谈线性无关、谈维数。**
前面几章摆弄的对象几乎全是 $n$ 维向量：线性组合、线性无关、极大无关组、秩、解空间，说的都是 $\mathbf{R}^{n}$ 里的事。可考场上冒出来的不只有向量：

- 所有 $2$ 阶矩阵凑成的集合，矩阵之间有加法，也能拿数去乘；
- 所有次数不超过 $2$ 的多项式 $a + bx + cx^{2}$ 凑成的集合，多项式之间也有加法、也能数乘；
- 齐次方程组 $AX = 0$ 的全部解凑成的集合，解向量之间当然也能相加、能数乘。

问题很实际：既然都有加法和数乘，这三个集合能不能也谈"线性无关""极大无关组""维数"？如果能，后面每碰到一种新对象就省一套语言；如果不能，就得先弄清它们差在哪一条上。
最容易想到的办法是"对着 $\mathbf{R}^{n}$ 一条条抄"：加法交换律、结合律、分配律、$1\alpha = \alpha$ ……把八条运算法则全验一遍。可这么干又慢又没底，真要碰上"不是"的情形，八条里断的是哪条也看不出来。凭感觉判更危险：$W = \{(x_1,x_2) \mid x_1x_2 \ge 0\}$ 就是第一、三象限连同坐标轴，看图妥妥地"能加能乘"，$(1,2)$ 在里面、$(-2,-1)$ 也在里面，可加起来是 $(-1,1)$，而 $(-1) \times 1 = -1 < 0$ —— 加法这一步就跑出去了。感觉在这里完全不顶用。

## <span class="hx hx-gap">🔴</span> 二、直接办法为什么不够

所以得先把"能谈线性代数"的条件写死，可三条土路都走不通：

- <span class="pit">**坑一 · 八条法则一条条验**</span>：八条里有一大半（交换律、结合律、分配律、$1\alpha = \alpha$）只要集合是从 $\mathbf{R}^{n}$ 里取的、加法数乘是常规的，就白送，验了也白验；真正可能出事的只有"封闭性"那一条，逐条硬验等于把时间花在不出事的地方；
- <span class="pit">**坑二 · 凭"看起来能加能乘"下结论**</span>：上面的 $W = \{(x_1,x_2) \mid x_1x_2 \ge 0\}$ 就是反例；再比如 $W = \{(x_1,x_2,x_3) \mid x_1 + x_2 + x_3 = 1\}$，看着也像"一张平面"，可 $(0,0,0)$ 代进去得 $0 = 1$，零向量根本不在里面。光看图、凭直觉，这两种都会判错；
- <span class="pit">**坑三 · 只顾验封闭、不问非空**</span>：空集对加法、对数乘"验起来也是封闭的"（里面没有元素可以拿来反），可空集不能当空间用；判定顺序要是先封闭后非空，遇上空集就会得出错误的结论。

## <span class="hx hx-intro">🟢</span> 三、于是引入：线性空间与子空间

于是引入**线性空间**（也叫向量空间）：设 $V$ 是一个非空集合，在它上面定义了"加法"与"数与元素的乘法"，如果对任意 $\alpha, \beta, \gamma \in V$ 和任意数 $k, l$，下面八条运算法则都成立，就称 $V$ 是线性空间：

$$
\begin{cases} \alpha + \beta = \beta + \alpha \\ (\alpha + \beta) + \gamma = \alpha + (\beta + \gamma) \\ \alpha + 0 = \alpha \\ \alpha + (-\alpha) = 0 \\ 1\alpha = \alpha \\ k(l\alpha) = (kl)\alpha \\ k(\alpha + \beta) = k\alpha + k\beta \\ (k + l)\alpha = k\alpha + l\alpha \end{cases}
$$

$V$ 的非空子集 $W$ 如果对 $V$ 的加法、数乘都封闭，就叫 $V$ 的子空间。考试里几乎只算子空间，所以要背的其实是三条判定。

上面那三个坑，逐个补上：

- <span class="fix">**坑一补上 · 八条能"批发"**</span>：只要加法、数乘就是原空间那一套，六条运算法则自动继承下来，需要单独检查的只剩"对加法封闭"和"对数乘封闭"，判定一下从八条缩成三条；
- <span class="fix">**坑二补上 · 有两把硬尺子**</span>：先看零向量在不在 —— $W = \{(x_1,x_2,x_3) \mid x_1 + x_2 + x_3 = 1\}$ 在第一步就出局；再挑两个元素做加法，看结果跑不跑出去 —— $W = \{(x_1,x_2) \mid x_1x_2 \ge 0\}$ 拿 $(1,2) + (-2,-1) = (-1,1)$ 一验就出局；
- <span class="fix">**坑三补上 · "非空"一句话就够**</span>：判定清单固定写成"非空、对加法封闭、对数乘封闭"三条，非空通常就是把零向量代进去，或者随手指出一个确实属于它的元素，一句话带过。

> 顺带提一句：集合里装的是什么并不重要 —— 矩阵、多项式、解向量都行，只要封闭，后面讲的"基""维数""线性变换"整套路数都能照搬到它头上。现在不懂"变换"不影响做题。

## <span class="hx hx-detail">🔵</span> 四、细节

<span class="lab">**定义**</span>：非空集合 $V$ 上定义了加法与数乘，且八条运算法则全成立，称 $V$ 为线性空间；$V$ 的非空子集 $W$ 若对加法、数乘都封闭，称 $W$ 是 $V$ 的子空间。
<span class="lab">**判定三条**</span>：① 非空；② 对加法封闭（任取 $\alpha, \beta \in W$，有 $\alpha + \beta \in W$）；③ 对数乘封闭（任取数 $k$ 与 $\alpha \in W$，有 $k\alpha \in W$）。三条都过才是子空间，缺一条就否。
<span class="lab">**算例**</span>：判 $W = \{(x_1,x_2,x_3) \mid x_1 + x_2 + x_3 = 0\}$ 是不是 $\mathbf{R}^{3}$ 的子空间。

- 非空：把 $(0,0,0)$ 代进去，$0 + 0 + 0 = 0$ 成立，说明 $W$ 里确实有元素；
- 对加法封闭：设 $\alpha = (a_1,a_2,a_3) \in W$、$\beta = (b_1,b_2,b_3) \in W$，即 $a_1 + a_2 + a_3 = 0$、$b_1 + b_2 + b_3 = 0$。那么 $\alpha + \beta = (a_1 + b_1, a_2 + b_2, a_3 + b_3)$，三个分量加起来是 $(a_1 + a_2 + a_3) + (b_1 + b_2 + b_3) = 0 + 0 = 0$，所以 $\alpha + \beta \in W$；
- 对数乘封闭：$k\alpha = (ka_1, ka_2, ka_3)$，三个分量之和为 $k(a_1 + a_2 + a_3) = k \times 0 = 0$，所以 $k\alpha \in W$。

三条全过，$W$ 是 $\mathbf{R}^{3}$ 的子空间。（它的基是 $(-1,1,0)$、$(-1,0,1)$，维数 $2$，怎么算基和维数看下一个点。）
<span class="pit">**两个必记的反例**</span>：

- $W = \{(x_1,x_2,x_3) \mid x_1 + x_2 + x_3 = 1\}$：$(0,0,0)$ 代进去得 $0 = 1$，零向量不在 $W$ 里，一句话否掉；
- $W = \{(x_1,x_2) \mid x_1x_2 \ge 0\}$：$(1,2) \in W$、$(-2,-1) \in W$，可 $(1,2) + (-2,-1) = (-1,1)$，此时 $(-1) \times 1 < 0$，加法不封闭，否掉。

<span class="key">**常用结论**</span>：

- 子空间必含零向量：非空加上对数乘封闭，取 $k = 0$ 得 $0\alpha = 0$ 就落在 $W$ 里；所以"零向量不在里面"可以直接当结论写；
- 齐次方程组 $AX = 0$ 的全部解 $N(A)$ 是 $\mathbf{R}^{n}$ 的子空间（解空间），$A$ 的列向量的全部线性组合 $R(A)$ 是 $\mathbf{R}^{m}$ 的子空间（列空间）；
- 两个子空间的交仍是子空间，并一般不是：$\mathbf{R}^{2}$ 里 $x$ 轴与 $y$ 轴都是子空间，$(1,0) + (0,1) = (1,1)$ 就不在它们的并里。

## <span class="hx hx-usage">🟣</span> 五、怎么用

1. 选择题：给一个集合（例如"所有行列式等于 $1$ 的 $2$ 阶矩阵""所有满足 $x_1x_2 = 0$ 的向量"）判断它是不是子空间；数二不要求，数一常以"下列集合是不是子空间"的小题出现（零向量一出局就否）。
2. 填空题：判断零向量属不属于某个集合，或者补一句"它不是子空间，因为……"；数二不要求，数一常在第一空就考"零向量在不在里面"，填"不在"再加一句理由。
3. 解答题：证明某个集合是子空间，或者把 $N(A)$、$R(A)$ 认成子空间之后再谈它的基与维数；数二不要求，数一常把它放在大题第一小问（先说明解空间、列空间是子空间），后面接着求基与维数。
