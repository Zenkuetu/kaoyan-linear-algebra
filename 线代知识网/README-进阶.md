# README-进阶：让关系图谱的**连线**按关系类型上色

## 为什么原生做不到

Obsidian 原生关系图谱只能给**节点**分组着色（`设置 → 关系图谱 → 颜色组`），**连线不能分别设色** —— 这是它的功能边界。本库已经为节点配好了颜色组（按 `基础`/`数一`/`数二` 标签），连线颜色需要装插件。

本库的 frontmatter 里已经按关系类型写好了属性，装插件后**开箱即用**：

```yaml
充要⇔:
  - "[[矩阵的秩|矩阵的秩]]"
充分⇒:
  - "[[可对角化的充要条件|可对角化的充要条件]]"
必要⇐:
  - "[[AA∗ = A∗A = ｜A｜E|AA* = A*A = ｜A｜E]]"
```

## 步骤

1. 安装插件 **Extended Graph**（设置 → 第三方插件 → 浏览 → 搜索 `Extended Graph`）。
2. 在该插件设置里打开三个开关（⚠️ 插件所有功能**默认关闭**，不开的话相关选项根本不显示）：

| 中文界面名 | 英文名 | 为什么必须开 |
| --- | --- | --- |
| **自动启用** | Auto enable | 不开的话插件在已打开的图谱视图里完全不生效 |
| **最大节点数** | Maximum number of nodes | 默认只有 20，本库有 100+ 节点，会被它自我保护禁用（弹「尝试处理过多节点」）|
| **链接** | Link types | 不开的话下面这些链接相关选项不出现 |

3. 在"链接"小节里打开：**链接着色**、**显示标签**、**标签颜色**；建议打开 **忽略行内链接**（让图谱只保留 frontmatter 里的类型边，避免同一对节点上出现重复边）。
4. 在 **特定颜色** 里按类型指定颜色：

| 类型 | 颜色 | 含义 |
| --- | --- | --- |
| `充要⇔` | 🟥 `#e5534b` | 两端可互换 |
| `充分⇒` | 🟧 `#e8873a` | 顺箭头蕴含 |
| `必要⇐` | 🟪 `#a882ff` | 逆箭头蕴含 |
| `无关` | ⬜ `#9aa0a6` | 既非充分也非必要 |
| `关联` | 🟩 `#3fb950` | 同源 / 构成 / 特例 |
| `章节` | 🔹 `#6e8ba8` | 结构边：知识点 → 所属章节页 |
| `索引` | 🔹 `#9a8fb5` | 结构边：汇总页 ↔ 总览 |

5. 打开图谱的箭头（原生 `设置 → 关系图谱 → 显示箭头`，以及插件的 **箭头** 功能）。

## 怎么看出"谁对谁充分/必要"

箭头方向 = 卡片方向（和每篇笔记"关系网"表格里的 `本点 ⇒ 对方` 一致），而**蕴含方向看标签上的符号**：

| 连线标签 | 读法 |
| --- | --- |
| `充要⇔` | 两个方向都成立 |
| `充分⇒` | **顺箭头**：起点 ⇒ 终点 |
| `必要⇐` | **逆箭头**：终点 ⇒ 起点（起点是终点的必要条件）|
| `无关` / `关联` | 不是蕴含关系，箭头只表示关系写在哪一端 |

原因：数学上"X 是 Y 的**必要**条件"等价于"Y 是 X 的**充分**条件"，光看箭头会读反，所以把符号直接写在标签里。

## 不想装插件

没关系 —— 关系类型在**每篇笔记的"关系网"小节**（默认折叠）和 **6 张 Canvas** 里都有：Canvas 的连线颜色与标签就是按这套规则生成的，打开 `01 关系网索引（章节结构）.canvas` 即可。
