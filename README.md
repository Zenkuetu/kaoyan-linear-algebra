# 考研数学 · 线性代数知识网（Obsidian 库）

一个用 [Obsidian](https://obsidian.md) 打开的线性代数复习库：**103 个知识点**、**164 条"充分 / 必要 / 充要 / 无关"关系边**，每篇笔记都按同一套结构写成，并且**每条关系都经过"反过来读一遍"的语义校验**。

> 不是公式手册，而是**按"为什么需要它"组织的知识网**：每个知识点都从痛点讲起，先摆出三条走不通的土办法，再引入正式定义，最后说清考法、易错点和 30 秒自测。

## 快速开始

1. 下载 [Obsidian](https://obsidian.md/download)（免费；本仓库**不打包**安装包）。
2. 到本仓库的 [Releases](../../releases) 页面下载最新版 ZIP（当前为 `linear-algebra-vault-v1.2.zip`；请以 Releases 页最新版为准）。
3. 解压，得到一个包含 `.obsidian` 与 `线代知识网` 两层内容的文件夹。
4. 在 Obsidian 里选择 **打开文件夹作为仓库（Open folder as vault）**，指向**这个解压出来的文件夹**（不是里面的 `线代知识网`）—— 这样样式片段（小节色条、坑标红）与关系图谱的节点配色会开箱即用。
5. 打开 `线代知识网/00 线性代数知识网总览` 开始看。

### 每篇笔记的固定结构

```
🟠 一、先看要解决什么      ← 痛点（不先给定义）
🔴 二、直接办法为什么不够   ← 三条走不通的土办法
🟢 三、于是引入            ← 逐条补上（对上三条坑）
🔵 四、细节                ← 定义 / 算例 / 规则
🟣 五、怎么用              ← 选择、填空、解答三种题型怎么考
⚠️ 六、易错点              ← 最容易踩的地方
🎯 七、30 秒自测           ← 三个自查问题（带折叠答案）
🕸️ 八、关系网              ← 与相邻知识点的充分必要关系（默认折叠）
🧭 九、导航
```

配套一份 CSS 片段（已随库启用）：小节带色条、行距放宽、坑是红的、补上是绿的，专门为了**盯着大段文字不累**。

## 考试范围标注

每篇都标了 `基础` / `数一` / `数二`：

- **基础**：数一、数二、数三共同要求（53 个）
- **数二**：数二也要求（37 个）
- **只标 `数一`**：即**数二不要求**（20 个，例如二次型的化标准形、正定性判定、向量空间与线性变换）

统计：103 个知识点中，**数二需掌握 83 个**，可跳过 20 个。

## 关系网怎么读

知识点之间的关系分五类，在 Canvas、笔记的"关系网"小节、以及（安装 Extended Graph 插件后的）Obsidian 关系图谱里都一致：

| 类型 | 颜色 | 含义 |
| --- | --- | --- |
| 充要 ⇔ | 🟥 | 两端可互换 |
| 充分 ⇒ | 🟧 | 起点是终点的充分条件 |
| 必要 ⇐ | 🟪 | 起点是终点的**必要**条件（终点 ⇒ 起点）|
| 无关 | ⬜ | 有联系但不成条件关系 |
| 关联 | 🟩 | 同源 / 构成 / 特例 |

**每条边都做过"读出来必须是真的"校验**：`iff` 要两个方向都真，`suff`/`need` 要只有单向成立且方向正确，`rel` 不能读成条件关系。164 条边里已有 132 条通过独立审计，其余按同口径修正；v1.1 新增的那条（"可交换 ↔ 特征向量共享"）另用精确有理数重算过（详见 `tools/HISTORY.md`）。

## 关系图谱的高级玩法（可选）

Obsidian 原生图谱只能给**节点**上色，不能给**连线**上色。本库的 frontmatter 已经按关系类型写好了属性（`充要⇔` / `充分⇒` / `必要⇐` / `无关` / `关联` / `章节` / `索引`），装上 [Extended Graph](https://community.obsidian.md/plugins/extended-graph) 插件后，连线就能按类型上色、并直接标出类型名。

配置方法（含中文界面词条对照）见 `线代知识网/README-进阶.md`。

## 怎么生成的（可复现）

这套库不是手写的，而是**数据 + 生成器**：

1. **数据层**：`tools/*.js` 里每个知识点一个对象（id、标题、标签、一句话、关系边），关系边单独放在 `tools/edges.js`。
2. **通俗层**：每篇笔记的正文（痛点/坑/补上/细节/用法/自测）以草稿形式放在 `tools/deep-v2/_draft/*.md`，用 `draft2json.mjs` 校验后转 JSON。
3. **生成**：`node tools/build.js <输出目录>` 生成 103 篇笔记 + 章节页 + 汇总页；`node tools/canvas-v2.js <输出目录>` 生成 6 张 Canvas。

自带的校验脚本（每次改动都会跑）：

```
check-notes.mjs        结构完整性 + LaTeX + 编号一致性 + 重复 ID
check-template.mjs     是否所有笔记都符合叙事骨架
check-links.mjs        所有双链可解析
check-mislinks.mjs     矩阵记号不会被误判为双链
check-oneline.mjs      "一句话"视觉宽度 ≤ 46
check-jargon.mjs       引入段不得越界使用后面章节的术语
check-connectivity.mjs 关系图连通性（当前 1 个连通块）
check-vault-connectivity.mjs  整库连通性
check-graph-config.mjs 图谱设置没被"运行中的 Obsidian"覆盖掉（配色组 / 箭头 / 连线着色）
verify-fix-landing.mjs 关键修复是否真的落在产物里
verify-commute-eigen.mjs  "可交换 ⇒ 特征向量共享"那条定理的精确有理数验证（解空间维数、公共特征向量、重根反例）
```
