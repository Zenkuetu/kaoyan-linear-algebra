## 1. `eig-def` ｜ 特征值与特征向量的定义 ｜ 标签：数一/数二

- **现有一句话要点**：Aα = λα（α≠0），λ 为特征值、α 为对应特征向量。
- **现有正文（要展开的核心）**：定义式是"特征向量被 A 作用后只伸缩、不转向"；α 必须非零。
- **现有性质/结论**：
    - α≠0 是定义的硬性要求
    - Aα = λα ⇔ (λI−A)α = 0
- **现有易错点**（放进"六、易错点"）：
    - 把零向量当特征向量
- **关系边**（仅供理解本点地位，正文不必照抄）：

    - 特征值的范围与估计 ⇒ 充分 ⇒ 本点：圆盘定理用于估计特征值位置

## 2. `eig-poly` ｜ 特征多项式与特征方程 ｜ 标签：数一/数二

- **现有一句话要点**：｜λI − A｜ 为特征多项式，｜λI−A｜=0 为特征方程，其根即全部特征值（含重数）。
- **现有正文（要展开的核心）**：n 次多项式在复数域内有 n 个根（计重数），实矩阵可能有复特征值。
- **现有性质/结论**：

- **现有易错点**（放进"六、易错点"）：

- **关系边**（仅供理解本点地位，正文不必照抄）：

## 3. `eig-vector-space` ｜ 特征子空间与特征向量的求法 ｜ 标签：数一/数二

- **现有一句话要点**：对每个 λᵢ 解齐次方程组 (λᵢI−A)x=0，其基础解系即属于 λᵢ 的线性无关特征向量。
- **现有正文（要展开的核心）**：属于 λᵢ 的特征向量全体加零向量构成子空间，维数 = n − r(λᵢI−A)。
- **现有性质/结论**：
    - 属于同一 λ 的特征向量的非零线性组合仍是特征向量
    - 不同特征值的特征向量线性无关
- **现有易错点**（放进"六、易错点"）：

- **关系边**（仅供理解本点地位，正文不必照抄）：

## 4. `eig-mult` ｜ 代数重数与几何重数 ｜ 标签：数一/数二

- **现有一句话要点**：代数重数 nᵢ 为 λᵢ 作为特征方程根的重数；几何重数 mᵢ = n − r(λᵢI−A)；恒有 1 ≤ mᵢ ≤ nᵢ。
- **现有正文（要展开的核心）**：几何重数 < 代数重数 ⇔ 不可对角化，这是判定不可对角化的核心。
- **现有性质/结论**：
    - mᵢ ≤ nᵢ
    - Σnᵢ = n
    - Σmᵢ ≤ n
- **现有易错点**（放进"六、易错点"）：
    - 把重数当成特征向量的个数
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 充分 ⇒ 特征值与特征向量的性质：几何重数≤代数重数 ⇒ 特征向量不够则不可对角化
    - 本点 ⇒ 充要 ⇒ 可对角化的充要条件：几何重数＝代数重数 ⇔ 可对角化
    - 特征子空间与特征向量的求法 ⇒ 充分 ⇒ 本点：解空间维数即几何重数
    - 向量组秩与线性表出的关系表 ⇒ 充分 ⇒ 本点：以少表多必相关 ⇒ 几何重数受限
