## 1. `eq-homo-sol` ｜ 齐次方程组 Ax = 0 ｜ 标签：基础

- **现有一句话要点**：必有零解；有非零解 ⇔ r(A) < n ⇔ 列组线性相关 ⇔ ｜A｜=0（方阵）。
- **现有正文（要展开的核心）**：齐次方程组永远相容，问题只在于"只有零解"还是"有无穷多解"。
- **现有性质/结论**：
    - Ax=0 有非零解 ⇔ r(A) < n
    - n 个未知数、n 个方程时有非零解 ⇔ ｜A｜=0
- **现有易错点**（放进"六、易错点"）：
    - 把"有非零解"的条件写成 r(A) ≤ n 之外的形式
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 基础解系：有非零解才谈基础解系
    - 本点 ⇒ 必要 ⇒ 齐次方程组的通解与解空间：通解以基础解系为构件
    - 高斯消元法与行阶梯形 ⇒ 充分 ⇒ 本点：消元即可判齐次解的情形
    - 齐次与非齐次解的关系 ⇒ 必要 ⇒ 本点：讨论基于齐次的解集情形
    - 克拉默法则 ⇒ 充分 ⇒ 本点：｜A｜≠0 ⇒ 齐次只有零解
    - 矩阵方程 AX = O 与 AB = O ⇒ 充要 ⇒ 本点：AB=O 即 B 的列都是齐次解
    - 可逆的充要条件（汇总枢纽） ⇒ 充要 ⇒ 本点：可逆 ⇔ 齐次只有零解

## 2. `eq-homo-structure` ｜ 基础解系 ｜ 标签：基础

- **现有一句话要点**：Ax=0 的解向量组的极大无关组；当 r(A)=r<n 时含 n−r 个向量 ξ₁,…,ξ_{n−r}。
- **现有正文（要展开的核心）**：基础解系不唯一，但向量个数恒为 n−r(A)。
- **现有性质/结论**：
    - 基础解系含 n − r(A) 个解向量
    - 任一解可唯一由基础解系线性表示
- **现有易错点**（放进"六、易错点"）：
    - 把自由未知量取值的组数当成解的个数（应是 n−r）
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 充分 ⇒ 齐次方程组的通解与解空间：基础解系的线性组合即通解
    - 高斯消元法与行阶梯形 ⇒ 充分 ⇒ 本点：自由未知量个数给出基础解系规模
    - 齐次方程组 Ax = 0 ⇒ 必要 ⇒ 本点：有非零解才谈基础解系

## 3. `eq-homo-general` ｜ 齐次方程组的通解与解空间 ｜ 标签：基础

- **现有一句话要点**：x = k₁ξ₁ + … + k_{n−r}ξ_{n−r}（kᵢ 任意）；所有解构成 n−r 维子空间（解空间）。
- **现有正文（要展开的核心）**：解空间维数 dim N(A) = n − r(A)，即"零度"，与秩定理对应。
- **现有性质/结论**：
    - 解集 = 基础解系的全部线性组合
    - dim N(A) + r(A) = n
- **现有易错点**（放进"六、易错点"）：
    - 通解中漏写任意常数 kᵢ
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 非齐次方程组的通解结构：非齐次通解＝特解＋齐次通解
    - 齐次方程组 Ax = 0 ⇒ 必要 ⇒ 本点：通解以基础解系为构件
    - 基础解系 ⇒ 充分 ⇒ 本点：基础解系的线性组合即通解
    - 同解方程组与公共解 ⇒ 必要 ⇒ 本点：同解判定需比较解集
    - 特征子空间与特征向量的求法 ⇒ 充分 ⇒ 本点：特征向量就是齐次方程组的非零解
    - 核与像（值域） ⇒ 充分 ⇒ 本点：核即齐次方程组的解空间

## 4. `eq-nonhomo-crit` ｜ 非齐次方程组 Ax = b 的相容性判别 ｜ 标签：基础

- **现有一句话要点**：有解 ⇔ r(A) = r(A,b)；无解 ⇔ r(A) < r(A,b)（此时 r(A)+1 = r(A,b)）。
- **现有正文（要展开的核心）**：判别只比较两个秩，特别地 r(A,b) 最多比 r(A) 大 1。
- **现有性质/结论**：
    - r(A)=r(A,b)=n ⇒ 唯一解
    - r(A)=r(A,b)<n ⇒ 无穷多解
- **现有易错点**（放进"六、易错点"）：
    - 只比较 r(A) 与 n 而漏掉增广矩阵的秩
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 系数矩阵与增广矩阵的关系：相容性判别用系数与增广矩阵的秩
    - 本点 ⇒ 必要 ⇒ 非齐次方程组的通解结构：先判有解再写通解
    - 高斯消元法与行阶梯形 ⇒ 充分 ⇒ 本点：化行最简形后比较两个秩
    - 齐次与非齐次解的关系 ⇒ 必要 ⇒ 本点：还需相容性判别
    - 克拉默法则 ⇒ 充分 ⇒ 本点：｜A｜≠0 ⇒ 唯一解
    - 方程组的几何意义（平面与直线） ⇒ 必要 ⇒ 本点：几何形态由秩决定

## 5. `eq-nonhomo-general` ｜ 非齐次方程组的通解结构 ｜ 标签：基础

- **现有一句话要点**：通解 = 特解 η* + 对应齐次方程组的通解；任意两解之差是对应齐次的解。
- **现有正文（要展开的核心）**：结构定理：解集是"仿射集"，不是子空间（除非 b=0）。
- **现有性质/结论**：
    - x = η* + k₁ξ₁ + … + k_{n−r}ξ_{n−r}
    - η₁,η₂ 为解 ⇒ η₁−η₂ 是 Ax=0 的解
- **现有易错点**（放进"六、易错点"）：
    - 把非齐次通解写成纯齐次形式，丢掉特解
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 逆矩阵的求法：矩阵方程求解常用逆矩阵
    - 非齐次方程组 Ax = b 的相容性判别 ⇒ 必要 ⇒ 本点：先判有解再写通解
    - 齐次方程组的通解与解空间 ⇒ 必要 ⇒ 本点：非齐次通解＝特解＋齐次通解

## 6. `eq-rank-relation` ｜ 系数矩阵与增广矩阵的关系 ｜ 标签：基础

- **现有一句话要点**：r(A) ≤ r(A,b) ≤ r(A)+1；两者相等 ⇔ 有解，相差 1 ⇔ 无解。
- **现有正文（要展开的核心）**：再结合 r(A) ≤ min{m,n} 与 n 的关系即可一次性判完所有情形。
- **现有性质/结论**：
    - r(A) ≤ r(A,b) ≤ r(A)+1
    - r(A,b)=r(A) ⇔ b 可由 A 的列组线性表示
- **现有易错点**（放进"六、易错点"）：
    - 忘记 r(A,b) 至多比 r(A) 大 1 这一上限
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 非齐次方程组 Ax = b 的相容性判别 ⇒ 必要 ⇒ 本点：相容性判别用系数与增广矩阵的秩
    - 矩阵的秩 ⇒ 必要 ⇒ 本点：相容性判别以秩为语言

## 7. `eq-cramer` ｜ 克拉默法则 ｜ 标签：基础

- **现有一句话要点**：n 个方程 n 个未知数且 ｜A｜≠0 时，xⱼ = ｜Aⱼ｜/｜A｜（Aⱼ 为第 j 列换成 b）。
- **现有正文（要展开的核心）**：仅适用于"方程数 = 未知数个数且系数行列式非零"的窄场景。
- **现有性质/结论**：
    - ｜A｜≠0 ⇒ 解存在且唯一
    - 齐次情形 ｜A｜≠0 ⇒ 只有零解
- **现有易错点**（放进"六、易错点"）：
    - 方程数与未知数个数不等时套用克拉默法则
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 充分 ⇒ 非齐次方程组 Ax = b 的相容性判别：｜A｜≠0 ⇒ 唯一解
    - 本点 ⇒ 充分 ⇒ 齐次方程组 Ax = 0：｜A｜≠0 ⇒ 齐次只有零解
    - 本点 ⇒ 必要 ⇒ ｜AB｜ = ｜A｜｜B｜：公式的分子分母都是行列式

## 8. `eq-homo-nonhomo` ｜ 齐次与非齐次解的关系 ｜ 标签：基础

- **现有一句话要点**：Ax=0 只有零解 ⇒ Ax=b 解唯一（若有解）；Ax=0 有非零解 ⇒ Ax=b 若有解则有无穷多解。
- **现有正文（要展开的核心）**：两套情形组合成四种可能：无解 / 唯一解 / 无穷多解 / 只有零解。
- **现有性质/结论**：
    - 无解与唯一解不可能同时出现
    - 无穷多解 ⇔ 有解且 r(A)<n
- **现有易错点**（放进"六、易错点"）：
    - 把"齐次只有零解"当成"非齐次一定有解"
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 齐次方程组 Ax = 0：讨论基于齐次的解集情形
    - 本点 ⇒ 必要 ⇒ 非齐次方程组 Ax = b 的相容性判别：还需相容性判别

## 9. `eq-samesol` ｜ 同解方程组与公共解 ｜ 标签：数一

- **现有一句话要点**：两个方程组同解 ⇔ 解集相同；求公共解可联立求解，或用一组的通解代入另一组。
- **现有正文（要展开的核心）**：同解判定常用：r(A)=r(B) 且 B 的行可由 A 的行线性表示（反之亦然）。
- **现有性质/结论**：
    - Ax=0 与 Bx=0 同解 ⇒ r(A)=r(B)
    - 公共解：联立两组方程求通解
- **现有易错点**（放进"六、易错点"）：
    - 仅由 r(A)=r(B) 断言同解
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 必要 ⇒ 齐次方程组的通解与解空间：同解判定需比较解集
    - 本点 ⇒ 充要 ⇒ 向量组的等价：同解 ⇔ 行向量组可相互线性表示

## 10. `eq-AX-O-AB-O` ｜ 矩阵方程 AX = O 与 AB = O ｜ 标签：数一

- **现有一句话要点**：AB = O ⇔ B 的每一列都是 Ax=0 的解 ⇒ r(A)+r(B) ≤ n（A 为 m×n）。
- **现有正文（要展开的核心）**：这是把矩阵等式翻译成方程组语言、进而用秩证明的经典转换。
- **现有性质/结论**：
    - AB=O ⇒ r(A)+r(B) ≤ n
    - B 的列向量都落在 A 的零空间中
- **现有易错点**（放进"六、易错点"）：
    - 用错 n：应为 A 的列数、也就是 B 的行数
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 充要 ⇒ 齐次方程组 Ax = 0：AB=O 即 B 的列都是齐次解
    - 本点 ⇒ 充分 ⇒ 秩的不等式（乘法与加法）：由 AB=O 得 r(A)+r(B) ≤ n
    - 秩的不等式（乘法与加法） ⇒ 充分 ⇒ 本点：乘法秩不等式特例即 AB=O 的秩和不等式

## 11. `eq-gauss` ｜ 高斯消元法与行阶梯形 ｜ 标签：基础

- **现有一句话要点**：对增广矩阵作初等行变换化为行最简形，选出主元，把自由未知量取为参数写出通解。
- **现有正文（要展开的核心）**：求秩、求基础解系、求通解、求极大无关组的统一操作平台。
- **现有性质/结论**：
    - 主元个数 = r(A)
    - 自由未知量个数 = n − r(A)
- **现有易错点**（放进"六、易错点"）：
    - 对增广矩阵作列变换（会改变解集）
- **关系边**（仅供理解本点地位，正文不必照抄）：
    - 本点 ⇒ 充分 ⇒ 齐次方程组 Ax = 0：消元即可判齐次解的情形
    - 本点 ⇒ 充分 ⇒ 基础解系：自由未知量个数给出基础解系规模
    - 本点 ⇒ 充分 ⇒ 非齐次方程组 Ax = b 的相容性判别：化行最简形后比较两个秩
    - 本点 ⇒ 充分 ⇒ A* 的秩与可逆性判定：解方程组可求伴随矩阵的秩
    - 初等变换（三种） ⇒ 充分 ⇒ 本点：初等行变换是消元法的操作

## 12. `eq-geometry` ｜ 方程组的几何意义（平面与直线） ｜ 标签：基础

- **现有一句话要点**：三个未知数时，每个方程表示一张平面；解的情况对应三平面的相交形态（一点、一条线、无公共点等）。

- **现有易错点**（放进"六、易错点"）：

- **关系边**（仅供理解本点地位，正文不必照抄）：
