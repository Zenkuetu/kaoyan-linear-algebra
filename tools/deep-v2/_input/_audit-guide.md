# 独立审校指南（审校代理必读）

你的角色：**独立审校**。这些内容不是你写的，你的任务不是"读一遍觉得没问题"，而是**动手把它算一遍**。
历史经验：前面几轮审校在"已经人工看过一遍"的内容里仍然查出 13 处错误，其中两处是推理层面的错
（把"不可逆"当成不能对角化的原因；满秩时把 $A^{*}$ 的列"送进核里"）。**只看文字是查不出来的。**

## 一、必须动手算的清单

| 检查项 | 做法 |
| --- | --- |
| 每一个算例 | 用脚本重算（临时脚本放系统临时目录，别留在项目里） |
| 每一条等式/化简 | 逐步核对，注意符号、下标的行列顺序 |
| 每一个反例 | 验算它**真的能反**：例如要反 $r(AB)=r(A)r(B)$，取 $A=B=O$ 无效（两边都是 0） |
| 每一条结论的前提 | 缺前提就是错误：如实矩阵才有 $r(A^{\mathrm{T}}A)=r(A)$；$n \ge 2$ 才有伴随矩阵的秩分级公式；$|kA|=k^{n}|A|$ 要 $A$ 为 $n$ 阶 |
| 词条本义 | 与简报里该知识点的"现有要点/性质/易错点"对照，检查有没有**说反、说过头、丢条件** |

## 二、文字层面的检查

1. **概念越界**：`pain` 的第一句不许出现本章之后的术语（每章的允许范围写在简报第 5 行）。第二、三节若用了后面章节的视角，必须明确标注"现在不懂不影响做题"。
2. **悬空引用**：`gap` 里的"坑一/坑二/坑三"与 `intro` 里的"坑N补上"必须一一对应，编号写法一致。
3. **循环论证**：不许用正要建立的规则去证明这条规则本身。
4. **范围（数一/数二/非数二）**：与简报里该点的标签一致；标签是 `非数二` 的点必须在 usage 里写明"数二不要求"。
5. **LaTeX**：矩阵是否用了 `pmatrix`（不是 bmatrix）；`$$` 是否独占一行；公式里有没有中文。
