### ONELINE
正负平方项各数几个就是惯性指数，$p+q=r(A)$

### PAIN
**惯性指数要解决的是：化标准形时正项、负项到底各有几个，能不能不问化法就数出来。**
拿一个具体的来：

$$
f = x_1^2 + 2x_1x_2 + 3x_2^2
$$

它的矩阵是 $A = \begin{pmatrix} 1 & 1 \\ 1 & 3 \end{pmatrix}$。现在问：化标准形之后会有几个正平方项、几个负平方项？

最容易想到的办法是硬算：配方得

$$
f = (x_1 + x_2)^2 + 2x_2^2
$$

两个平方项前面都是正号（$1$ 和 $2$），所以是两个正项、零个负项。看着挺顺，可是换个算法就慌了：正交变换法的标准形是 $\lambda_1y_1^2 + \lambda_2y_2^2$，$\lambda$ 是特征值，算出来是 $2 \pm \sqrt{2} \approx 0.586$ 和 $3.414$ —— 系数完全不一样，凭什么"正项个数"还是两个？万一某种替换能把某个正项翻成负项呢？光看"配出来几个正号"，心里没底。

### GAP
所以需要一个不依赖具体替换的"数数"办法，土办法各有各的漏：

- **坑一 · 只看一个标准形就下结论**：配方法给 $(x_1+x_2)^2 + 2x_2^2$（两个正项），正交变换法给 $0.586y_1^2 + 3.414y_2^2$（也是两个正项）—— 两个标准形长得完全不同，凭"我配出来是这样"就断言，遇到别的替换就心虚；
- **坑二 · 把 $p+q$ 记成 $n$**：$f = x_1^2 - x_2^2$ 看着是二元二次型，$p + q = 2 = n$ 没问题；但加上一个系数为零的 $x_3$，变成 $\mathrm{diag}(1,-1,0)$，$p = 1$、$q = 1$，$p + q = 2$ 而 $n = 3$ —— 秩亏时两者不等，按 $n$ 数就会凭空多出一个平方项；
- **坑三 · 用"系数大小"判断正负项**：$f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 配上 $2(x_1+\frac{1}{2}x_2)^2$ 与 $\frac{3}{2}x_2^2$，两个系数 $2$ 和 $\frac{3}{2}$ 都大于零；换成正交变换得 $1y_1^2 + 3y_2^2$ —— 系数从 $\frac{3}{2}$ 变成 $3$，"哪个大哪个小"完全靠不住，靠得住的只有**符号**。

### INTRO
于是引入**惯性指数**：把二次型化成标准形后，**正平方项的个数**叫正惯性指数，记 $p$；**负平方项的个数**叫负惯性指数，记 $q$；两者之差 $p - q$ 叫**符号差**。

上面那三个坑，逐个补上：

- **坑一补上 · 个数是"怎么化都不变"的量**：不管是配方得的两个正项，还是正交变换得的 $0.586, 3.414$ 两个正项，$p$ 都是 $2$；这不是巧合 —— 换任何可逆替换，正项个数都不会变（这就是惯性定理），所以数一次就够，不必担心换算法翻车；
- **坑二补上 · 秩把零项单独管起来**：$p + q = r(A)$，$r(A)$ 是二次型的秩。$n = 3$、$\mathrm{diag}(1,-1,0)$ 时 $r = 2$，于是 $p + q = 2$、零项 $n - r = 1$，三个数各归各位，不会数错；
- **坑三补上 · 只看符号，不看大小**：$p$、$q$ 只统计正负项的**个数**，$3y_1^2 + y_2^2$ 与 $y_1^2 + 100y_2^2$ 的惯性指数完全一样（都是 $p = 2$、$q = 0$）。正交变换法里"系数就是特征值"这句话，用的也只是特征值的**正负**。

> 顺带提一句：这套"数符号个数"的做法，到附录会换一个说法 —— 它是二次型在可逆替换下的完全不变量。名字换了，数法一模一样，现在不懂它照样能把题做完。

### DETAIL
**定义**：把 $n$ 元二次型 $f$ 用可逆线性替换化成标准形 $d_1y_1^2 + \dots + d_ny_n^2$，其中正系数的个数记为 $p$（**正惯性指数**），负系数的个数记为 $q$（**负惯性指数**），$p - q$ 叫**符号差**。

**两条算法**（都要先有二次型的矩阵 $A$）：
- 配方/正交变换：数标准形里正、负平方项的个数；
- 看特征值：$p$ = $A$ 的正特征值个数，$q$ = $A$ 的负特征值个数（特征值按重数计）。前提是 $A$ **实对称**。

**算例一**：$f = x_1^2 + 2x_1x_2 + 3x_2^2$，$A = \begin{pmatrix} 1 & 1 \\ 1 & 3 \end{pmatrix}$。配方得 $f = (x_1+x_2)^2 + 2x_2^2$，两个正项，所以 $p = 2$、$q = 0$，符号差 $2$。用特征值核一遍：$\lvert \lambda E - A \rvert = \lambda^2 - 4\lambda + 2$，$\lambda = 2 \pm \sqrt{2} \approx 0.586,\ 3.414$，两个都正，$p = 2$、$q = 0$，一致。$p + q = 2 = r(A)$（$\lvert A \rvert = 2 \neq 0$，满秩）。

**算例二**：$f = 2x_1^2 + 2x_1x_2 - 4x_2^2$，$A = \begin{pmatrix} 2 & 1 \\ 1 & -4 \end{pmatrix}$。$\lvert A \rvert = -9 < 0$，所以特征值一正一负；实算 $\lambda^2 + 2\lambda - 9 = 0$ 给 $\lambda = -1 \pm \sqrt{10} \approx -4.16,\ 2.16$，于是 $p = 1$、$q = 1$，符号差 $0$，$p + q = 2 = r(A)$。

**算例三**（秩亏）：$f = x_1^2 - x_2^2$ 配上不出现的 $x_3$，矩阵是 $\mathrm{diag}(1,-1,0)$。这里 $p = 1$、$q = 1$、$r(A) = 2$，于是 $p + q = 2 < n = 3$，零项有 $n - r = 1$ 个。**别把 $p+q$ 记成 $n$。**

**常用结论**：
- $p + q = r(A)$，且零项个数 $= n - r(A)$；
- $p = n$（没有负项、没有零项）等价于 $f$ 正定；
- 前提提醒："$p$ 等于正特征值的个数"要求 $A$ 是**实对称**矩阵；非对称矩阵摆出来的特征值不参与这套统计。

### USAGE
1. 选择题：给一个标准形或给矩阵，问正、负惯性指数与符号差；或者问"下列二次型中与 $f$ 有相同惯性指数的是哪个"。**数二也要求**掌握惯性指数与符号差，惯性指数是数二判定合同的唯一工具，这类题数二必考。
2. 填空题：填 $p$、$q$、$p-q$，或是利用 $p + q = r(A)$ 反求矩阵里的参数（如已知 $p = 1$、$q = 1$ 反解待定系数）。数二同样要求。
3. 解答题：判定两个二次型（两个实对称矩阵）是否合同 —— 分别算出 $(p, q)$，相同就合同。**数二也要求**用惯性指数判合同，这是数二在这一章的重点题型。

### SELFCHECK
1. 求 $f = x_1^2 + 2x_1x_2 + 3x_2^2$ 的正、负惯性指数与符号差。（配方 $(x_1+x_2)^2 + 2x_2^2$，$p = 2$、$q = 0$，符号差 $2$。）
2. 三阶矩阵 $\mathrm{diag}(1,-1,0)$ 的 $p$、$q$、$r$ 各是多少？$p + q$ 等于 $n$ 吗？（$p = 1$、$q = 1$、$r = 2$；$p + q = 2 < 3$，不相等。）
3. 判断：$3y_1^2 + y_2^2$ 与 $y_1^2 + 100y_2^2$ 的惯性指数相同吗？（相同，都是 $p = 2$、$q = 0$ —— 只看符号个数，不看系数大小。）
