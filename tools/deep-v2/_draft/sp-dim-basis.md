### ONELINE
极大无关组叫基；基里向量的个数叫维数

### PAIN
**基与坐标要解决的问题是：在一个空间里挑一组"基准向量"，让每个向量的表示方式唯一、读数能算。**
具体到一道题：$\mathbf{R}^{3}$ 里给了三个向量 $\alpha_1 = (1,0,0)$、$\alpha_2 = (0,1,0)$、$\alpha_3 = (1,1,0)$，问它们能不能当 $\mathbf{R}^{3}$ 的基准，能不能把 $\beta = (0,0,1)$ 表示出来；再给一组 $\gamma_1 = (1,0,0)$、$\gamma_2 = (1,1,0)$、$\gamma_3 = (1,1,1)$，求 $\beta = (3,2,1)$ 用它们表示的系数。
最容易想到的办法是"数个数"：$\mathbf{R}^{3}$ 是 $3$ 维的，手上正好 $3$ 个向量，那就能当基准。拿 $\alpha$ 试一下就崩了：设 $\beta = c_1\alpha_1 + c_2\alpha_2 + c_3\alpha_3$，按分量列出来是

$$
\begin{cases} c_1 + c_3 = 0 \\ c_2 + c_3 = 0 \\ 0 = 1 \end{cases}
$$

第三个式子 $0 = 1$ 直接自相矛盾 —— **个数一样多，照样表示不出来**。个数这个条件根本不够。

### GAP
所以得换一套办法挑基准，可三条土路都不通：

- **坑一 · 只数个数不问线性无关**：上面三个向量个数确实和 $\mathbf{R}^{3}$ 的维数一样都是 $3$，但 $\alpha_3 = \alpha_1 + \alpha_2$，是"白搭的一个"，表示 $(0,0,1)$ 时第三个分量只能给出 $0 = 1$，无解；个数够不等于能当基；
- **坑二 · 现场凑系数**：想表示 $\beta = (3,2,1)$ 就临时凑三个数，凑出来了也不知道对不对、更不知道唯不唯一；而且凑法只对这一个向量有效，题目换一批向量就得从头再凑一遍；
- **坑三 · 把"分量个数"当维数**：$\mathbf{R}^{3}$ 里每个向量都写 $3$ 个数，于是看到子空间 $W = \{(x_1,x_2,x_3) \mid x_1 + x_2 + x_3 = 0\}$ 也顺手写"$3$ 维"；其实 $W$ 里的向量被一个方程卡住，只有 $2$ 维 —— 分量个数和维数是两件事。

### INTRO
于是引入**基、维数与坐标**：线性空间 $V$ 中的一组向量 $\alpha_1, \alpha_2, \cdots, \alpha_n$，如果 ① 线性无关，② $V$ 中任一向量都能由它们线性表示，就称它是 $V$ 的一组**基**；基所含向量的个数 $n$ 叫 $V$ 的**维数**，记作 $\dim V$；向量 $\beta$ 写成 $\beta = x_1\alpha_1 + x_2\alpha_2 + \cdots + x_n\alpha_n$ 时，系数排成的 $(x_1,x_2,\cdots,x_n)$ 就叫 $\beta$ 在这组基下的**坐标**。

上面那三个坑，逐个补上：

- **坑一补上 · "个数"和"无关"两条一起查**：$n$ 维空间里，$n$ 个向量构成基 $\iff$ 这 $n$ 个向量线性无关（多一个必相关、少一个必表示不全）；上面的 $\alpha_1,\alpha_2,\alpha_3$ 因为相关而出局，$\gamma_1,\gamma_2,\gamma_3$ 无关，就能当基；
- **坑二补上 · 坐标不用凑，解一次方程就唯一**：设 $\beta = c_1\alpha_1 + \cdots + c_n\alpha_n = d_1\alpha_1 + \cdots + d_n\alpha_n$，两式相减得 $(c_1 - d_1)\alpha_1 + \cdots + (c_n - d_n)\alpha_n = 0$，由线性无关只能 $c_i = d_i$，所以坐标唯一 —— 解出来是什么就是什么，不用猜；
- **坑三补上 · 维数看基里有几个向量**：$\dim W$ 等于 $W$ 的基所含向量的个数，跟向量写几个分量无关；$W = \{(x_1,x_2,x_3) \mid x_1+x_2+x_3 = 0\}$ 的基是 $(-1,1,0)$、$(-1,0,1)$，只有 $2$ 个，所以 $\dim W = 2$。

> 顺带提一句：坐标这东西下一节"过渡矩阵"要用，本附录后面"线性变换的矩阵"更是一路都用它 —— 向量本身没变，换一组基，"读数"就换一套。现在不懂"过渡矩阵"不影响做题。

### DETAIL
**定义**：$V$ 中线性无关且能表示 $V$ 中一切向量的向量组叫基，基中向量个数叫维数；表示系数叫坐标，坐标在给定基下唯一。
**判定流程**（判 $n$ 个向量是不是 $n$ 维空间的基）：① 看个数，必须是 $n$ 个；② 验无关，设 $c_1\alpha_1 + \cdots + c_n\alpha_n = 0$，只有零解才算过；实际算的时候把向量按列排成方阵 $A$，算 $\lvert A \rvert \ne 0$ 或 $r(A) = n$ 都等价；③ 两条都过就是基（不必再验"能不能表示"）。
**算例**：$\alpha_1 = (1,0,0)$、$\alpha_2 = (0,1,0)$、$\alpha_3 = (1,1,0)$ 不是 $\mathbf{R}^{3}$ 的基。
把它们按列排成 $A = \begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 1 \\ 0 & 0 & 0 \end{pmatrix}$，第三行全是 $0$，所以 $\lvert A \rvert = 0$、$r(A) = 2 < 3$，线性相关，出局。再直接验证一次"表示不出来"：设 $(0,0,1) = c_1\alpha_1 + c_2\alpha_2 + c_3\alpha_3$，分量方程是 $c_1 + c_3 = 0$、$c_2 + c_3 = 0$、$0 = 1$，最后一式矛盾，无解。
**算例（换一组，全步骤）**：$\gamma_1 = (1,0,0)$、$\gamma_2 = (1,1,0)$、$\gamma_3 = (1,1,1)$ 是 $\mathbf{R}^{3}$ 的基，求 $\beta = (3,2,1)$ 的坐标。

- 先验是基：排成 $B = \begin{pmatrix} 1 & 1 & 1 \\ 0 & 1 & 1 \\ 0 & 0 & 1 \end{pmatrix}$，上三角且对角元全非零，$\lvert B \rvert = 1 \ne 0$，三个向量无关，个数又是 $3$，所以是基；
- 再设 $\beta = x_1\gamma_1 + x_2\gamma_2 + x_3\gamma_3$，逐分量列方程：第一个分量 $x_1 + x_2 + x_3 = 3$，第二个分量 $x_2 + x_3 = 2$，第三个分量 $x_3 = 1$；
- 回代：由 $x_3 = 1$ 得 $x_2 = 2 - 1 = 1$，再得 $x_1 = 3 - 1 - 1 = 1$，所以坐标是 $(1,1,1)$；
- 核验：$\gamma_1 + \gamma_2 + \gamma_3 = (1 + 1 + 1, 0 + 1 + 1, 0 + 0 + 1) = (3,2,1)$，对得上。

**常用结论**：

- $n$ 维空间中任意 $n$ 个线性无关的向量都构成基（这条最省事：只要无关，不必再验表示）；
- 坐标在给定基下唯一；$\mathbf{R}^{n}$ 的标准基 $e_1 = (1,0,\cdots,0)$、$\cdots$、$e_n = (0,\cdots,0,1)$ 下，坐标就是分量本身；
- 含零向量的向量组一定不是基（必线性相关）；无关组不够 $n$ 个时可以添向量扩成基；
- 有限维空间中，子空间的维数不超过所在空间的维数；且 $\dim W = \dim V$ 时 $W = V$。

### USAGE
1. 选择题：判断给定的 $n$ 个向量是不是 $\mathbf{R}^{n}$ 的基（常给含参向量，问参数取何值时构成基）；数二不要求，数一就爱出含参向量，算的其实是 $\lvert A \rvert \ne 0$，顺带考"个数够不够 $n$"。
2. 填空题：求某个向量在给定基下的坐标，或者求解空间、列空间的维数；数二不要求，数一常考坐标怎么解出来，填完代回原式验一下最快。
3. 解答题：先证一组向量是基、再求坐标（这是下一节求过渡矩阵的准备动作），或者在求线性变换的矩阵时写一句"取定一组基"；数二不要求，数一常把它当求过渡矩阵、求变换矩阵的第一问。
