### ONELINE
齐次通解是基础解系的任意线性组合

### PAIN
**齐次方程组的通解与解空间要解决的问题是：把"无穷多个解"当成一个整体，说清它的规模和形状。**
具体一点：$x_1 + 2x_2 + 3x_3 = 0$ 这一个方程，解有多少个？把 $x_2, x_3$ 当自由未知量，每取一组数就是一个解，解有无穷多个 —— 这无穷多个解凑成的整个集合长什么样？两个这样的集合能不能比大小？
最容易想到的判断办法是"数方程个数"：觉得方程写得越多、解就越少。可下面这组写了两行，一望而知"解不比一行时少"：

$$
\begin{cases} x_1 + 2x_2 + 3x_3 = 0 \\ 2x_1 + 4x_2 + 6x_3 = 0 \end{cases}
$$

第二行左边恰好是第一行的 $2$ 倍，代进去等于什么都没加 —— 方程写了两行，解集跟只写一行时一模一样。**"方程个数"根本不是能用来衡量解集大小的量。**

### GAP
"数方程个数"这条路是错的，类似的土办法也站不住：

- **坑一 · 把解集当成一堆点逐个看**：无穷多个点既列不完也画不出，更回答不了"两个方程组的解集谁包含谁"；
- **坑二 · 用方程个数估解集的规模**：上面那组两行等于一行；反过来"方程越多解越少"也不成立 —— 只要新添的行是原来几行的倍数，多写一行也白写；
- **坑三 · 用"未知数个数减方程个数"猜独立方向**：上面是 $3$ 个未知数、$2$ 个方程，$3 - 2 = 1$，猜成"解是一条直线"，可它实际是一张平面（两个独立方向）—— 因为起作用的不是方程行数 $2$，而是 $r(A) = 1$。

### INTRO
于是引入**齐次方程组的通解与解空间**。把基础解系的线性组合写出来：

$$
x = k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r}
$$

（$k_1, \dots, k_{n-r}$ 为任意常数），这就是通解，一句公式写完全部解。
全部解凑成的集合还有一个好性质：两个解加起来还是解，一个解乘任意常数还是解（代进去左边是 $0 + 0 = 0$、$k \times 0 = 0$），所以这个集合习惯上叫**解空间**；它的"独立方向个数"（也就是基础解系里向量的个数）记作 $d$，则

$$
d = n - r(A), \qquad r(A) + d = n
$$

也就是说：主元占掉 $r(A)$ 个未知数，剩下的 $n - r(A)$ 个才能自由取值，每个自由未知量正好给出一个独立方向。

上面那三个坑，逐个补上：

- **坑一补上 · 无穷多个解用"有限个方向 + 任意系数"打包**：方程 $x_1 + 2x_2 + 3x_3 = 0$ 的通解是 $x = k_1(-2,1,0)^{\mathrm{T}} + k_2(-3,0,1)^{\mathrm{T}}$，两个方向配上任意系数，一句公式顶掉无穷多个点；
- **坑二补上 · 规模看秩，不看方程行数**：上面那两行的组，第二行是第一行的 $2$ 倍，消元后第二行整行变 $0$，$r(A) = 1$，自由度 $d = 3 - 1 = 2$，与"只有一个方程"时完全相同；
- **坑三补上 · 独立方向个数有公式，不用猜**：$d = n - r(A)$，上面是 $3 - 1 = 2$ 个方向（一张过原点的平面），不是"$3$ 减方程个数"算出来的 $1$。

> 顺带提一句：这里的"解空间"到附录里会被正式定义为"子空间"（对加法与数乘封闭的集合），"独立方向个数"也会被叫作"维数"。名字更正式，内容就是上面两句话，现在不懂不影响做题。

### DETAIL
**定义**：$Ax = 0$ 的全部解构成的集合叫解空间；$x = k_1\xi_1 + \cdots + k_{n-r}\xi_{n-r}$（$k_i$ 任意）叫齐次方程组的通解。
**别名**：解空间到附录里会被叫"零空间"，现在不懂不影响做题。
**封闭性验算**：设 $A\eta_1 = 0$、$A\eta_2 = 0$，则 $A(\eta_1 + \eta_2) = A\eta_1 + A\eta_2 = 0 + 0 = 0$，$A(k\eta_1) = kA\eta_1 = 0$ —— 两解之和、任一解的倍数仍是解，这就是"解集能当空间看"的全部理由。
**规模公式**：$d = n - r(A)$，即 $r(A) + d = n$ —— 这里的 $d$ 就是基础解系里向量的个数；只有零解时 $d = 0$，解集里只剩零向量一个点。
**算例**：求下面齐次方程组的通解，并说清解集的规模。

$$
\begin{cases} x_1 + 2x_2 + 3x_3 = 0 \\ 2x_1 + 4x_2 + 6x_3 = 0 \end{cases}
$$

$$
\begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \end{pmatrix} \xrightarrow{\;r_2 - 2r_1\;} \begin{pmatrix} 1 & 2 & 3 \\ 0 & 0 & 0 \end{pmatrix}
$$

**读解**：主元只有 $1$ 个，$r(A) = 1$；$x_2, x_3$ 是自由未知量，$d = n - r(A) = 3 - 1 = 2$。由行最简形读出 $x_1 = -2x_2 - 3x_3$，把 $(x_2, x_3)$ 依次取 $(1,0)$、$(0,1)$：

$$
\xi_1 = (-2,1,0)^{\mathrm{T}}, \qquad \xi_2 = (-3,0,1)^{\mathrm{T}}
$$

**通解**：$x = k_1\xi_1 + k_2\xi_2$，$k_1, k_2$ 为任意常数。
**验算**：$\xi_1$ 代回，$-2 + 2 \times 1 + 3 \times 0 = 0$、$2 \times (-2) + 4 \times 1 + 6 \times 0 = 0$；$\xi_2$ 代回，$-3 + 0 + 3 = 0$、$-6 + 0 + 6 = 0$，都成立。
**三种规模对照**：$r(A) = n$ 时 $d = 0$（只有零解）；$r(A) = n - 1$ 时 $d = 1$（解是一条过原点的直线）；$r(A) = n - 2$ 时 $d = 2$（解是一张过原点的平面）。
**易错提醒**：通解里的 $k_1, k_2$ 是任意常数，不能漏写、也不能当成具体数；$k_1 = k_2 = 0$ 时得到的正是零解。

### USAGE
1. 选择题：给两个齐次方程组比较解集的"大小"（比自由度 $n - r(A)$），或者问"解集是一条直线还是一张平面"。
2. 填空题：写出齐次方程组的通解（必须带任意常数），或者由"解空间有两个独立方向"反求 $r(A) = n - 2$。
3. 解答题：求通解是常考的第一问；第二问常接着问"再添一个方程以后解集怎么变"，本质是把两个解集的范围取交集。
