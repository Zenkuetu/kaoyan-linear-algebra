### ONELINE
换任何可逆替换，正负平方项都不变，规范形唯一

### PAIN
**惯性定理要解决的是：凭什么说"正、负平方项的个数"是二次型自己的性质，而不是我选替换选出来的。**
拿一个具体的来：

$$
f = 2x_1^2 + 2x_1x_2 + 2x_2^2
$$

它有标准形 $3y_1^2 + y_2^2$（正交变换法，特征值 $1,3$），也有标准形 $2u_1^2 + \frac{3}{2}u_2^2$（配方法）。两个标准形系数完全不同，可"正项都是 $2$ 个、负项都是 $0$ 个"这一点是一样的。现在问：**换一个更刁钻的可逆替换，能不能把某个正项改成负项？** 比如找一个替换让标准形变成 $y_1^2 - y_2^2$？

最容易想到的路是硬试：既然替换矩阵 $C$ 只要可逆，$C$ 有无穷多个，随便取一个 $C = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ 算算看 $C^{\mathrm{T}}AC$ 是什么 —— 算出来 $\begin{pmatrix} 2 & 3 \\ 3 & 6 \end{pmatrix}$，交叉项又冒出来了，还得再化。试一个两个还行，无穷多个怎么试得完？而且"试试看能不能凑出反例"这种思路，就算试了一百个都失败，也说明不了第一百零一个不行。

### GAP
所以要的不是"多试几个"，而是一个能**证明**的说法，土办法的三个缺口是：

- **坑一 · 用"标准形相同"代替"惯性指数相同"**：$3y_1^2 + y_2^2$ 与 $2u_1^2 + \frac{3}{2}u_2^2$ 明明是两个不同的标准形，如果按"标准形要一模一样才算等价"来判，就会得出"这两个 $f$ 不等价"的荒唐结论 —— 可它们就是同一个 $f$；
- **坑二 · 以为可逆替换能把正项翻成负项**：直觉上"可逆"很宽松，好像什么都能变。可是 $(x_1+x_2)^2 + 2x_2^2$ 这种"平方和"的结构，怎么倒腾都倒腾不出减号来 —— 光凭直觉说不清，得有个定理兜底；
- **坑三 · 换了替换就重新数一遍**：每换一个替换就重新配方、重新统计正负项，费时费力，而且没法回答"所有替换都不行"这句话。

### INTRO
于是引入**惯性定理**：二次型经过**任意**可逆线性替换化成标准形，**正平方项的个数 $p$ 与负平方项的个数 $q$ 都不变**；换句话说，$p$、$q$ 是二次型（以及它的实对称矩阵）在可逆替换下**固有的不变量**，因而**规范形唯一**。

上面那三个坑，逐个补上：

- **坑一补上 · 比不变量，不比长相**：$3y_1^2 + y_2^2$ 与 $2u_1^2 + \frac{3}{2}u_2^2$ 的标准形长得不同，但各自都能再缩成同一个规范形 $z_1^2 + z_2^2$（前者除 $\sqrt{3}$、后者除 $\sqrt{2}$ 与 $\sqrt{\frac{3}{2}}$）—— 比较二次型一律走规范形，一律看 $(p, q)$；
- **坑二补上 · 定理说了变不了**：由惯性定理，$f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 的 $p = 2$、$q = 0$ 在任何可逆替换下都成立，所以存在替换把它变成 $y_1^2 - y_2^2$ 这件事**从根上就不可能**（后者 $p = 1$、$q = 1$）；
- **坑三补上 · 数一次，终身有效**：既然是不变量，随便挑一个方便的替换化一次就够 —— 配方法最快，数完 $p$、$q$ 就收工。而且"$f$ 与 $g$ 合同 $\iff$ 它们的 $p$、$q$ 分别相同"这句话，直接给出判定两个二次型/两个实对称矩阵是否合同的**可操作办法**。

> 顺带提一句：这套"找不变量"的做法，到附录会换一个说法 —— 它是二次型在合同关系下的完全不变量。名字换了，数法一模一样，现在不懂它照样能把题做完。

### DETAIL
**定理**：设实二次型 $f = x^{\mathrm{T}}Ax$ 经可逆线性替换 $x = Cy$ 化为标准形 $d_1y_1^2 + \dots + d_ny_n^2$，则其中正系数的个数 $p$、负系数的个数 $q$ 与所取的可逆替换 $C$ **无关**。

**两条直接推论**：
1. **规范形唯一**：任何实二次型的规范形都唯一确定为

$$
y_1^2 + \dots + y_p^2 - y_{p+1}^2 - \dots - y_{p+q}^2
$$

2. **合同判据**：两个实二次型（或两个实对称矩阵）合同 $\iff$ 它们的正、负惯性指数分别相同。

**算例一（两个标准形，同一惯性指数）**：
- $f_1 = 2x_1^2 + 2x_1x_2 + 2x_2^2$，矩阵 $\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$，特征值 $1, 3$，正交变换后标准形 $3y_1^2 + y_2^2$；
- $f_2 = 5x_1^2 + 4x_1x_2 + 2x_2^2$，矩阵 $\begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}$，$\lvert \lambda E - A \rvert = \lambda^2 - 7\lambda + 6 = (\lambda-1)(\lambda-6)$，特征值 $1, 6$，正交变换后标准形 $6y_1^2 + y_2^2$。
两个标准形（$3y_1^2+y_2^2$ 与 $6y_1^2+y_2^2$）系数完全不同，但**正项都是 $2$ 个、负项都是 $0$ 个**，所以规范形都是 $z_1^2 + z_2^2$，$f_1$ 与 $f_2$ 合同。验算 $f_2$ 的性质：配方 $f_2 = 5(x_1 + \frac{2}{5}x_2)^2 + \frac{6}{5}x_2^2$，代 $(1,1)$ 得 $5 \times \frac{49}{25} + \frac{6}{5} = \frac{49}{5} + \frac{6}{5} = 11$，而 $f_2(1,1) = 5 + 4 + 2 = 11$，一致。

**算例二（可逆替换确实把系数变了，但符号个数没变）**：对 $f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 分别取
- $C_1 = \begin{pmatrix} 1 & -\frac{1}{2} \\ 0 & 1 \end{pmatrix}$（$\lvert C_1 \rvert = 1$），得 $2y_1^2 + \frac{3}{2}y_2^2$；
- $C_2 = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$（$\lvert C_2 \rvert = -1$），得 $3y_1^2 + y_2^2$。
系数从 $(2, \frac{3}{2})$ 变成 $(3, 1)$，**两个都是正的** —— 系数会变，符号个数不变。

**算例三（秩同但不合同）**：$\mathrm{diag}(1,-1,0)$ 与 $\mathrm{diag}(1,1,0)$ 的秩都是 $2$，看起来"很像"，但前者 $p = 1, q = 1$、后者 $p = 2, q = 0$，惯性指数不同，**不合同**。这说明"秩相等"远不足以保证合同（数二特别容易在这里翻车）。

**常用结论**：
- $p$、$q$ 是不变量，$p + q = r(A)$，零项个数 $= n - r(A)$；
- 判断合同只数 $(p, q)$，不必真的找出替换矩阵 $C$；
- 前提提醒：本定理对**可逆**替换成立（换句话说是对合同关系）；如果允许不可逆的替换，$p$、$q$ 都可能变小，"不变量"就没了。

### USAGE
1. 选择题：判断两个二次型是否合同、是否等价（同规范形）；或者问"某个二次型的规范形是什么"。**数二要求了解惯性定理**，这类题数二会出现，做法就是分别数 $(p, q)$ 再比较。
2. 填空题：由"两二次型合同"反求参数（惯性指数分别相同），或填规范形、填 $p$、$q$。数二同样要求。
3. 解答题：证明或应用"$f$ 与 $g$ 合同 $\iff$ 惯性指数分别相同"，以及用秩 + 惯性指数否掉错误的合同判断。**数二要求**掌握惯性定理，并且同样要求掌握化标准形的手法（正交变换法/配方法）。

### SELFCHECK
1. $f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 与 $g = 5x_1^2 + 4x_1x_2 + 2x_2^2$ 合同吗？（合同 —— 两者的标准形分别是 $3y_1^2 + y_2^2$ 与 $6y_1^2 + y_2^2$，$p$、$q$ 分别相同，规范形都是 $z_1^2 + z_2^2$。）
2. 判断：能不能找到一个可逆替换把 $f = 2x_1^2 + 2x_1x_2 + 2x_2^2$ 化成 $y_1^2 - y_2^2$？（不能 —— 由惯性定理 $p = 2, q = 0$ 不变，而目标式的 $p = 1, q = 1$。）
3. $\mathrm{diag}(1,-1,0)$ 与 $\mathrm{diag}(1,1,0)$ 合同吗？理由是什么？（不合同 —— 秩虽然都是 $2$，但 $(p,q)$ 分别是 $(1,1)$ 与 $(2,0)$，惯性指数不同。）
